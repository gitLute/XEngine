# XEngine

Игровой движок на C#/.NET. Целевой мир трёхмерный: окружение из мешей и
карт высот, персонажи и эффекты — билборды, две переключаемые проекции,
плоское затенение, единая плотность текстуры во всём мире.

**Состояние: рефакторинг.** Legacy-реализация на OpenTK и двумерной физике
Box2D не собирается на Linux и удаляется на этапе 15 плана; всё новое
пишется в `src/`. Сейчас сделаны инфраструктура решения (этап 1), математика
двумерная (этап 0) и трёхмерная (этап 2), окно и цикл кадра (этап 3).

Требования к продукту, запреты и план работ — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Состав

| Каталог | Содержание |
|---|---|
| `src/XEngine.Mathematics` | математика на `System.Numerics`: углы, прямоугольники, фигуры, коллизии, интерполяция, кривые, случайность. Двумерная и трёхмерная части: векторы, кватернионы, матрицы и проекции, AABB, сфера, капсула, луч, плоскость, пирамида видимости, плотность текселя |
| `src/` | проекты движка по слоям; правило зависимостей — 5.2 |
| `src/XEngine.Core` | конфигурация движка и журнал; далее ECS, сцены, реестры, дескрипторы |
| `src/XEngine.Windowing` | контракты окна и часов, реализация окна на Silk.NET, фиксированный шаг, цикл кадра |
| `tools/AtlasBuilder` | сборка текстурных атласов на этапе сборки, вне слоёв движка |
| `tools/WindowSample` | проверочный пример окна для критерия приёмки этапа 3; запускается вручную |
| `assets/` | шейдеры, конфигурация, атласы, модели; `assets/textures/source` — исходники для `AtlasBuilder` |
| `tests/` | тесты: математика, ядро, окно и цикл, проверка запретов, инструмент сборки атласов |
| `samples/Sandbox` | демонстрация возможностей; появится на этапе 15 |
| `XEngine/` | legacy-код на OpenTK и Box2D. В решение не входит и не правится, удаляется на этапе 15 |
| `docs/` | дополнительные документы и ADR |
| `tmp/`, `out/` | временные файлы и артефакты сборки; содержимое не хранится |

Листинги кода в `ARCHITECTURE.md` — эскизы контрактов, а не готовая
реализация: переносить их без переработки и тестов нельзя.

## Сборка и тесты

Нужен .NET SDK 10.

```bash
dotnet build XEngine.sln -warnaserror
dotnet test XEngine.sln
```

## Сборка атласа

```bash
dotnet run --project tools/AtlasBuilder -- --source assets/textures/source --output assets/textures
```

Инструмент проверяет разметку регионов и пишет `atlas.png` с `atlas.json`.
Подробности — в [tools/AtlasBuilder/README.md](tools/AtlasBuilder/README.md).

## Проверка окна

```bash
dotnet run --project tools/WindowSample
```

Создаёт окно и выполняет кадры с очисткой; закрывается по требованию
пользователя. Тесты с настоящим окном идут только по требованию: без дисплея
GLFW падает нативно и уносит процесс тестов, поэтому обычный `dotnet test`
такие тесты пропускает.

```bash
XENGINE_WINDOW_TESTS=1 dotnet test tests/XEngine.Windowing.Tests
```

Подробности — в [tools/WindowSample/README.md](tools/WindowSample/README.md).

## Правила, проверяемые автоматически

Сборка с `-warnaserror` включает анализаторы из `.editorconfig`
(`CA1062`, `CA1819`, `CA2227`, `CA1848`, `CA2007`, `CA1031`, правила стиля
и именования). Запреты — ссылки на бэкенды в ядре, рефлексия где-либо в
`src/`, `Console` и `Debug` вне `ILogSink` — проверяет
`tests/XEngine.Architecture.Tests`, поэтому обычный `dotnet test` останавливается
на нарушении. В CI те же проверки выполняются для ветки `Refactor`.
