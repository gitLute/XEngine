# XEngine

2D-игровой движок на C#/.NET: ECS, сцены, спрайты, ввод, физика Box2D, OpenGL через Silk.NET.

**Состояние: рефакторинг.** Ядро переписывается. Рабочая часть — математическая
библиотека; остальное находится в стадии проектирования.

## Состав

| Каталог | Содержание |
|---|---|
| `src/XEngine.Mathematics` | математика на `System.Numerics`: углы, прямоугольники, фигуры, коллизии, интерполяция, кривые, случайность. Собрана и покрыта тестами |
| `XEngine/` | старая реализация на OpenTK (legacy). Не собирается на Linux, удаляется на этапе 10. Источник поведения для сверки |
| `ARCHITECTURE.md` | архитектура, каталог дефектов, требования, план миграции по этапам |
| `tests/` | тесты |

Новый код движка пишется в `src/`. Листинги кода в `ARCHITECTURE.md` — эскизы
контрактов для ознакомления, копировать их нельзя.

## Сборка и тесты

Нужен .NET SDK 9 или новее.

```bash
dotnet build XEngine.sln
dotnet test XEngine.sln
```

## Запуск

Запускать пока нечего: хост-приложения нет, `XEngine.sln` содержит только
библиотеку и её тесты. Демонстрация (`samples/Sandbox`) появится на этапе 10
плана миграции.
