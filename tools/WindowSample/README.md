# Проверка окна и цикла кадра (этап 3)

Пример создаёт окно, выполняет кадры с очисткой и завершает работу. Служит
для критерия приёмки этапа 3 «появляется окно с очисткой кадра» — проверку с
экраном выполняет человек, потому что тест по общему правилу не должен
требовать окна (17.6).

## Запуск

```bash
dotnet run --project tools/WindowSample
```

Окно закрывается по требованию пользователя. Чтобы ограничить число кадров
и не ждать закрытия вручную:

```bash
dotnet run --project tools/WindowSample -- 640 480 300
```

Аргументы: ширина, высота, число кадров. Программа завершается с кодом 0.

## Что должно быть видно

| Что | Как проверить |
|---|---|
| Окно появляется | заголовок `XEngine`, размер по умолчанию 1280x720 |
| Кадр очищается | окно одноцветное, тёмно-синее, без мерцания и мусора |
| Окно изменяемо | перетащите рамку: содержимое остаётся одноцветным, без полос |
| Окно закрывается | крестик или Alt+F4: программа завершается с кодом 0 |
| Частота кадров ограничена | кадры идут ровно, без рывков; по умолчанию включена синхронизация с развёрткой |

Программа печатает в журнал фактические числа: сколько кадров выполнено,
сколько шагов симуляции и частота кадров в секунду. Ориентир — частота
около 60 и примерно одно число шагов на каждый шестьдесятый секунды. Если
частота в тысячи раз в секунду, а шагов единицы, значит кадр не показывается:
синхронизация не работает, время кадра почти не проходит.

## Тесты с настоящим окном

Четыре теста проверяют создание, размер, фокус и запрос закрытия. По умолчанию
они пропущены: без дисплея GLFW падает нативно и уносит процесс тестов вместе
с остальными, а такое перехватить нельзя.

```bash
XENGINE_WINDOW_TESTS=1 dotnet test tests/XEngine.Windowing.Tests
```

Пропуски видны отдельной строкой и не выглядят успехом: в обычном прогоне
`dotnet test XEngine.sln` остаётся зелёным без дисплея.

## Если окно не открывается

Сообщение `GLFW не смог открыть окно` означает, что у процесса нет доступа к
серверу окон. Проверьте переменные окружения:

```bash
echo "DISPLAY=$DISPLAY WAYLAND_DISPLAY=$WAYLAND_DISPLAY"
```

Пустые значения означают, что запускать не из чего. Если переменные заданы, а
окно не открывается, причину нужно искать в окружении запуска: процесс не
имеет доступа к сессии, в которой запущен.
